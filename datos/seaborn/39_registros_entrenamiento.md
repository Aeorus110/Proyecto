# Registros de entrenamiento para la unidad 39

Datos sintéticos creados para este curso. Simulan dos ejecuciones de entrenamiento ya calculadas y no representan el rendimiento de un modelo real.

## Esquema

| Columna | Tipo | Descripción |
| --- | --- | --- |
| `epoca` | entero | Iteración ordenada del entrenamiento. |
| `modelo` | texto | Configuración identificada como `base` o `ajustado`. |
| `lote` | texto | Identificador de la ejecución. |
| `perdida_validacion` | decimal | Pérdida observada en validación. |
| `exactitud_validacion` | decimal | Proporción de aciertos en validación. |
| `tiempo_s` | entero | Duración de la época en segundos. |

No contiene datos personales ni requiere conexión a Internet.
