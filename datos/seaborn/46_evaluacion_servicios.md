# Evaluación de servicios para el proyecto 46

Datos sintéticos creados para este curso. Simulan veinticuatro observaciones de dos canales y dos versiones de un servicio. No contienen datos personales ni describen un sistema real.

Cada fila agrupa una medición de peticiones por hora, latencia, porcentaje de errores, satisfacción y energía. Las pautas observadas solo son válidas para esta muestra simulada; no justifican decisiones reales ni relaciones causales.
