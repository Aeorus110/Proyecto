# Evaluaciones de configuraciones para la unidad 42

Datos sintéticos creados para este curso. Simulan resultados repetidos de tres configuraciones y dos turnos; no son resultados de un modelo real.

| Columna | Descripción |
| --- | --- |
| `configuracion` | Grupo categórico: base, regularizada o compacta. |
| `turno` | Grupo categórico: mañana o tarde. |
| `exactitud_pct` | Exactitud simulada en porcentaje. |
| `tiempo_ms` | Tiempo de respuesta simulado en milisegundos. |

Cada combinación de configuración y turno tiene seis observaciones. Las diferencias aparentes no permiten atribuir causalidad ni estimar rendimiento real.
