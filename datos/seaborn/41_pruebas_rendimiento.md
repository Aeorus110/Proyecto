# Pruebas de rendimiento para la unidad 41

Datos sintéticos creados para este curso. Simulan pruebas controladas de dos configuraciones de un sistema y no describen un producto, servicio o modelo real.

| Columna | Tipo | Descripción |
| --- | --- | --- |
| `prueba_id` | entero | Identificador de la prueba simulada. |
| `configuracion` | texto | Configuración simulada: `base` o `ajustada`. |
| `tamano_entrada_mb` | entero | Tamaño de entrada en megabytes. |
| `latencia_ms` | entero | Tiempo de respuesta simulado en milisegundos. |
| `carga_cpu_pct` | entero | Uso simulado de CPU en porcentaje. |

Las variables se han construido para practicar relaciones visuales. Un patrón en estos datos no demuestra cómo se comportaría un sistema real ni identifica la causa de sus diferencias.
